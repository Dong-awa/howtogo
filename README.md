# HowToGo | 问道

**我的世界道路标记与实时导航**
**Road marking and real-time navigation for Minecraft**

在 Xaero's World Map 上绘制道路，然后按类似于Google地图的方式导航：选目的地、选交通方式、选路线偏好，先看路线再出发，可选语音播报。

Draw roads on Xaero's World Map, then navigate the way a maps app works: pick a destination, pick a travel mode, pick a route preference, look at the route before you set off — with optional voice announcements.

- 模组 ID：`howtogo`
- 支持版本：Minecraft **1.21.1** / NeoForge **21.1.x**
- 运行侧：**纯客户端**（不需要装在服务器上）
- 最新版本：0.2.0

## 前置模组

| 模组                    | 必要性    | 说明                                              |
| --------------------- | ------ | ----------------------------------------------- |
| **Xaero's World Map** | **必需** | 所有道路与路线都渲染在它上面。缺少时模组会在日志报错并停用渲染层。               |
| XaeroLib              | 必需     | 随 World Map 一起提供，无需额外安装。                        |
| Xaero's Minimap       | 可选     | 读取小地图路标点作为目的地。                                  |
| Create（机械动力）          | 可选     | 自动读取轨道信息，将轨道映射为铁路；车站作为目的地。                      |
| MTR（我的世界铁路）          | 可选     | 读取 MTR 的车站与线路，作为本模组自己的目的地与公共交通线路。               |
| MCPhone               | 可选     | 在手机里多出一个「问道导航」应用（打开目的地选择界面）。                    |

可选模组**全部通过注册名或反射读取**，`build.gradle` 里没有任何一个的依赖：没装它们时对应图层为空，其余功能不受影响，它们改版本也不会让本模组编译不过。

## 功能

### 画路与维护

- 在世界地图上直接绘制道路折线，六个等级：**高速公路 / 公路 / 小路 / 铁路 / 水路 / 冰道**（颜色与线宽不同）。
- **吸附**：靠近已有节点或路段时自动吸附；按 `Alt` 可自由放置。开着机械动力时也会吸附到它的铁轨上。
- **命名**：命名后整条路（含所有转折段）共用同一个名字；地图上每条路只显示一次标签。
- **单行道**：选中一条路（或把光标放在路上）按 `O`，它在三种状态里循环：**双向 → 单行道（顺着画的方向）→ 单行道（逆着画的方向）→ 双向**。地图上会沿着这条路画出**箭头**，指向允许通行的方向，所以「哪条路是单行、朝哪边」不用点开任何界面就能看出来。
  - 开关作用于**整条路**（同一等级、中间不被路口打断的一整段），而不是光标下那一小截：一条弯了两个弯的街，只把其中一段设成单行不是任何人会做的事。
  - 一条路的两个半截可能是从不同方向画的，所以标记单行时会**沿着整条路重新定向**每一段，而不是把同一个值写上去——否则弯道两侧会各走一个方向。
  - **所有交通方式都遵守**，包括步行：一条街之所以是单行，是因为它是什么（窄巷、站台出口、单车道桥），本模组没有信息去判断它属于哪一种，所以「行人可以不管」这种规则是替玩家发明的。想让行人不受限，就在旁边画一条小路。
- **地点标记（POI）**：把任意位置标成地点，可选类型：**地点 / 资源点 / 商店 / 站点**。类型只影响地图显示与缩放时的取舍，不影响导航。
- **撤销 / 重做**：最多 64 步。
- 路网拓扑自洽：在路段中间落点会**真正拆分**该路段并在交点建立节点。
- **只看着连上不算连上**：两条路交叉而过、或差一格没接上，路由器本来不会互通；`repair_road_joins`（默认开）会先把这种「看起来接了」的地方修好——节点落在路段上就拆开它，两条路交叉就互相打断，然后把这些几乎重合的节点并成一个路口。只在「同一辆车能同时走这两条路」且高度相近时才并，所以桥还是桥。想完全按画的样子走，把它关掉即可。

### 导航仪（物品）

- **右键**打开「选择目的地」界面；鼠标悬停时 tooltip 显示当前行程（没有在导航时显示为待机）。

- **合成**（有序，九格全满）：四角 **铁锭**、四边 **纸**、中心 **指南针**。
  
  ```
  铁锭   纸    铁锭
   纸   指南针   纸
  铁锭   纸    铁锭
  ```

- 拿到指南针后配方会自动解锁并出现在配方书里（由 `data/howtogo/advancement/recipes/navigator.json` 负责）。

### 导航

- **交通方式**：步行 / 驾车 / 公共交通。三者可走的道路等级不同，因此**同一组起终点会得到不同的路线**：
  - 步行：高速、公路、小路、冰道
  - 驾车：高速、公路
  - 公共交通：铁路、水路、**冰道**（冰上划船是地图上最快的线路）
- **路线偏好**：最快时间 ↔ 最短距离；可**避开**指定道路等级（例如不想走水路）；可**优先大路**（小路代价 ×1.6，只在必要时才走）。
- **预计到达时间**按「交通方式 + 道路等级」计算，不是单一速度：公路 9、铁路/水路 8、冰道 40、步行 4.0~5.6 格/秒。
- **先预览再出发**：选好目的地、方式、偏好后，路线会先画在选择界面的地图上，确认无误再按「导航到这里」。
- **路线不绕远**：如果所选方式比直接走过去更慢，或该方式在当前路网无解，会**说明原因并改为按步行规划**，而不是给一条荒唐的绕路或一条直线。
- **单行道会被遵守**：规划只在允许的方向上走单行道，三种交通方式一视同仁。所以把一条街设成单行之后，反向的路线会改走别的路（或者在真的没有别的路时如实报「没有路线」），公共交通的线路如果站序和单行方向相反，线路配置界面里那一站也会标红。
- **不拉直线**：接驳段（首末离开路网的那一段）有距离上限，超过就直接报「没有路线」，不会画一条横穿地图的直线。上限是**驾车与公共交通 64 格**，**步行 4096 格**——后者实际上等于没有上限：没路的时候人本来就是直线走过去的，只是按离开路面的速度计时，而一个 64 格的上限会让「明明就在眼前、但离路 65 格」的地方回答「没有路线」，那是唯一无法执行的答案。上限在这里只防一件事：一个打错的坐标变成一条通往世界尽头的路线。
- **转向提示**：面板与地图读数显示距离与转向；播报距离按路况缩放（步行 50m、公路驾车 100m、高速驾车 300m、铁路 300m、冰道 500m）。
- **转弯判定要求朝向**：与路口齐平时，只有当你大致转向该方向（≤45°）才算转过；直行穿过路口不会被误判为转过。

### 公共交通线路

按线路走，而不是按最近的车站走。

- **线路配置界面**（世界地图上按 `L`，需先按 `R` 进入编辑模式）：左列是线路，中列是这条线的**站点顺序**，右列是所有可加的站点。新建、重命名、删除、调序、删站都在同一屏完成——一条六站线路不该是十几次界面切换。
- **线路有自己的类型**（铁路 / 水路 / 公路 / 冰道）。类型决定它能在哪些道路上跑，所以「这条路走不通」是可以在保存前就看见的：中列里**接不上一站的站点显示为红色**。
- **站点来源**：①你自己标记为「站点」的地点（可改名、可改类型）；②机械动力车站；③MTR 车站。后两者只读——它们的名字与类型属于那个模组，在这里改会得到一条描述着「不存在的车站」的线路。
- **只读线路可以复制**：MTR 的线路会列在线路表里并标注 `[MTR]`，按「复制为我的」就得到一份可以随意改的副本。
- **规划方式**：站点是有向图的节点，同一条线相邻两站之间是边，Dijkstra 找最省时间/最短距离的走法。**没有可用线路就如实说没有公共交通路线**，不会假装成公交把你塞进最近的一段轨道。
- **等车时间**：`transit_wait_seconds`（默认 60 秒）在每次上车时计一次，换乘再计一次；它同时参与搜索和预计时间——省 40 秒走路却多等 2 分钟的车，没有人会坐。
- **换乘站**：同一位置有两条及以上线路共用的站点会画成**橙色方块**（尺寸与普通站点相同）。只有两个标记在屏幕上真的重叠时才融合成一个，拉近看就分开。

### 机械动力铁路（自动识别）

装了 **Create（机械动力）** 时，铁路会被**自动识别**并画在世界地图上，无需手画：

- **数据来自 Create 自己的轨道图**。优先读 Create 客户端的轨道网络（`CreateClient.RAILWAYS`），读到的是 Create 自己的节点坐标与贝塞尔曲线，所以弯道是平滑曲线而不是阶梯。读不到时（没装 Create、类被改名、图还没同步）回退为**扫描 `create:track` 方块**，按方块自己的 `shape` 轴相连。两种来源**只有一种会成为当前图层**，不会重复计数。
- **识别靠方块注册名，不引用任何 Create 类**。所以 `build.gradle` 里没有 Create 依赖，Create 改名或换版本不会让我们编译不过；日志前缀 `[HowToGo] Create track layer:` 会说明当前用的是哪种来源。
- **铁路只读，但可以命名**。Create 拥有那段几何：移动节点、拆分、删除、改等级都不会提供，因为下一次读取（最多 1 秒后）就会覆盖掉。名称是**唯一**可以改的东西，也存在**单独的文件**里（见下方数据文件），不写进道路网络。
  - 命名与选中都按**整条铁路线**生效：`Shift` 点击选中时高亮整条线，`N` 命名时整条线共用同一个名字（与手画道路一致）。名字随地图缩放显示为浅蓝色标签。
  - 名称不绑在路段 id 上（每次重建 id 都会重排），而是绑在**该段的两个端点坐标**上，所以重建、重载、切换识别来源都不会丢。
- **画路时可以吸附到铁路**：编辑模式下，光标附近没有手画道路时，吸附会落到铁路上，让你把一条路的端点正好接在铁轨上。吸附到铁路只取**位置**（黄色吸附环），不会拆分或连接铁路——它不是编辑器拥有的几何。
- **车站算作地点**：Create 的车站会以地名形式标在世界地图上（与 POI 同色），并出现在目的地列表的「机械动力车站」数据源里，可直接作为导航目的地。站名取自 Create（玩家给车站起的名字）；回退到方块扫描时拿不到站名，就用坐标显示为「车站 x, z」。
- **可关闭**：`create_train_tracks = false` 即可关掉整个图层；扫描半径与速度也可调（见配置表）。

### MTR（我的世界铁路，自动识别）

装了 **MTR** 时，它的车站与线路会读进来，变成问道自己的站点与公共交通线路：

- **同样是反射只读**：不引用任何 MTR 类，MTR 没装、改名或换版本都不会影响本模组；`mtr_transit = false` 可整体关掉。
- **只读到玩家附近的那一部分，而且记得以前读到的**。MTR 把它的世界放在自己的服务端，只把玩家附近的数据发给客户端，所以任何一次读取都只是一个窗口。问道把每次读到的东西**合并保存**（线路、车站、轨道），走出同步范围后线路不会凭空消失——车站会留下，线路会留下，那条线的轨道也会留下。
- **线路按类型映射**：列车 / 缆车 → **铁路**线路，船 → **水路**线路；其它类型（飞机，或 MTR 以后新加的类型）**不猜**，直接不处理。
- **站点取的是站台位置**。车站的中心是整个区域的中点，大站的这个点离轨道很远；列车停的是站台，所以线路的站点取**站台的中点**，读不到站台时才退回区域中心。
- **短线路不凑数**：客户端还没收到的车站会被跳过而不是随便找个位置顶替；剩下不足两站的线路根本不会被列出来——一条没有行程可坐的线路只会回答「没有路线」。
- **每条线路可以自己决定要不要标记轨道**。MTR 的协议里**没有「这条线走哪段轨道」这个信息**，所以问道是反推的：对线路上每一对相邻站点，在 MTR 的轨道上规划一次，走过的那些轨道就是这条线实际走的轨道，然后以**只读的铁路/水路道路**形式标上去，让公交车程沿着 MTR 真正铺的轨道来算。
  - 线路配置界面里，每条 MTR 线路行尾有一个方块，**点亮＝沿这条线标记轨道（轨/水），熄灭＝不标记**。默认值来自 `mtr_auto_route_marks`（默认开）；每条线给过的答案单独记住。
  - 关掉标记的线路不会贡献任何轨道，它的站点就按老规矩去匹配**你画的路**——这正是「线路本来就走在你已经画好的路/水路上」时想要的答案。
  - 标记出来的道路**从不保存进你的路网，也从不可编辑**，和 MTR 的线路本身一样是只读图层。

### 地图显示面板

世界地图左上角有一块可拖动的小面板（`地图显示`），管的是「现在地图上画什么」：

- **每个道路等级一个开关**（高速 / 公路 / 小路 / 铁路 / 水路 / 冰道），**每类地点一个开关**（地点 / 资源点 / 商店 / 站点），外加**公共交通线路**总开关。这是自己的偏好，存在一个单独的文件里，跟存档无关。
- **离远了会按等级自动取舍**，顺序是算出来的而不是猜的：高速与冰道**永远不隐藏**（缩小看地图，看的就是「哪儿有快路」），然后依次是小路 → 公路 → 水路 → 铁路；地点这边先舍商店，再舍站点，再舍普通地点，**资源点最后才舍**（它本来就是值得从远处专程去的东西）。**公共交通线路从不因为缩小而消失**——它是本模组自己的主题，也是地图上唯一不能由道路推出来的东西。
- 两种规则走的是同一个入口（`MapFilter`），所以面板上的开关和缩放规则不可能互相矛盾。
- 面板是**屏幕覆盖层**而不是地图的一部分，所以它不会被地图画出来的线路、标记、名字盖住，点击也不会被地图截走。标题行就是拖动把手（位置会被记住），标题右侧的方块把面板卷起／展开。

### 显示

- **地点标识**：每个地点（自己放的 POI + 机械动力车站 + MTR 车站）在世界地图、导航 HUD 面板的小地图、以及目的地选择界面的地图上都有一个**黄色方块**。标识在所有缩放下都显示（缩小时文字会被抑制，标识不会——缩小时正是最需要它的时候）；编辑模式下车站的标识也照样显示，但不可编辑。
- **名字的大小跟着缩放走**，而且缩小时是**按比例变小直到仍然看得清**，放大时增长得很慢（大约到 38 倍才到最大字号）——一个名字是标签，不是测量结果，早早顶到最大只会让所有缩放级别看起来一样。名字与它标注的目标一起缩放：地点名到标记的距离跟着名字大小走，所以缩小的时候名字会自动贴近标记。
- **线上名字顺着线的方向写**，不再横着压在斜路上，并且**取字体行高的一半**，让道路从字中间穿过而不是浮在字旁边；地点与车站名保持水平，因为它们是点标签而不是线上的名字。
- **名字放不下就不显示**：当名字的宽度超过它所标注的**整条路**（不是单个路段——带弯的路是多个路段共用一个名字），整条名字就不画，避免它比路还长、读起来像在标注旁边的东西。
- **导航 HUD 面板**：旋转小地图（北向指示）、转向箭头、剩余距离与时间、进度条。
- **语音播报**（使用 Minecraft 原版 TTS，可在界面开关）：转弯前、现在转弯、到达、偏离路线。
- **选择目的地界面**：搜索框、可拖拽缩放的地图、地点列表、交通方式与偏好控件；界面**不暂停游戏**。

## 操作

| 操作                  | 作用                                          |
| ------------------- | ------------------------------------------- |
| `R`                 | 切换道路编辑模式                                    |
| 左键                  | 放置节点                                        |
| `Alt` + 左键          | 自由放置（不吸附）                                   |
| 右键                  | 结束当前道路 / 清除                                 |
| `Shift` + 点击        | 选中整条路；点在自动识别的铁路上则选中那条铁路线                    |
| `<` / `>`           | 切换道路等级                                      |
| `N`                 | 命名：优先作用于选中项，否则作用于光标所在处——道路整条、地点（POI）、或整条铁路线 |
| `O`                 | 单行道：选中或光标所在的那条路在 双向 / 顺向单行 / 逆向单行 之间循环       |
| `P`                 | 放置地点（POI）                                   |
| `L`                 | 打开线路配置界面（公共交通线路）                            |
| `Ctrl` + 左键         | 在地图上直接选定目的地（无需进入编辑模式；从地图开始导航只有这一种方式）        |
| `Del` / `Backspace` | 删除选中                                        |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做                                     |
| 滑轮                  | 选择界面地图缩放                                    |

编辑模式下屏幕右下角会竖排显示这些快捷键，前两行（绘制状态与路网统计）在左下角。地图显示面板用鼠标直接拖标题行即可移动位置，标题右侧方块卷起／展开。

**哪些要先按 `R`**：绘制、`Shift` 选中、`N` 命名、`P` 放地点、`L` 线路配置、`<` `>` 改等级、删除、撤销重做——都是编辑操作，必须先进入编辑模式。
**哪些不用**：`Ctrl` + 左键在地图上选目的地，拿导航仪右键打开选择界面，以及拖动地图显示面板。

## 配置

客户端配置由 NeoForge 生成，位于 `config/howtogo-client.toml`，也可从 **模组列表 → HowToGo | 问道 → 配置** 打开图形界面修改。主要项：

| 键                                  | 默认                         | 说明                                             |
| ---------------------------------- | -------------------------- | ---------------------------------------------- |
| `default_travel_mode`              | `"walk"`                   | 默认交通方式：`walk` / `drive` / `transit`            |

| `on_road_tolerance_blocks.*`       | 按等级宽度                      | 每个等级「还算在路上」的容差，影响偏离判定                          |

## 数据文件

| 路径                                          | 内容                                                       |
| ------------------------------------------- | -------------------------------------------------------- |
| `config/howtogo/<存档>/<维度>.json`             | 该存档该维度的道路网络（节点、路段、名称、地点与地点类型）                            |

| `config/howtogo/<存档>/<维度>-lines.json`       | 公共交通线路（线路名、类型、按顺序的站点）。单独一个文件，所以它出问题也碰不到你的路网             |

## 构建此模组

需要 JDK 21。

```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk-21.0.11"
.\gradlew.bat build          # 产物：build/libs/howtogo-0.2.0.jar
.\gradlew.bat runClient      # 开发环境启动客户端
```

`libs/xaeroworldmap-neoforge-1.21.1-*.jar` 以 `compileOnly` 方式参与编译——Xaero 的地图是闭源的，不在公共 Maven 上。它使用官方映射，因此不需要 reobf。开发环境运行时该 jar 会被放入 `run/mods/`。

`tools/routing-harness/` 是不需要启动游戏的检查器：把纯逻辑（路网、规划、MTR 导入、缩放取舍）在一份手写的桩上跑一遍断言，`run-fast.ps1` 复用已解析的 classpath，几秒钟出结果。

### 切换分支后构建失败？先清缓存

`.gradle/`、`build/`、`run/` 都在 `.gitignore` 里，所以**切分支不会清掉它们**。而每条分支是不同的 Minecraft、不同的加载器，Fabric 分支还是不同的映射命名空间——Loom 按映射的哈希给缓存文件命名，不按分支名，于是同一个目录里会堆出好几套。用错了那一套，就报成这样：

```
Failed to setup Minecraft
java.lang.IllegalArgumentException: Cannot remap access widener from namespace 'official'. Expected: 'intermediary'
```

这是 Loom 在建 Minecraft 的时候抛的，看着像源码问题，**不是**。本分支源码里根本没有 access widener（`validateAccessWidener` 是 `NO-SOURCE`）。

```powershell
powershell -ExecutionPolicy Bypass -File tools\reset-caches.ps1
```

它清掉本项目的构建缓存，然后**从冷状态重新构建**来验证。加 `-Deep` 会连全局 Loom 存储（按 Minecraft 版本）和 Gradle 构建缓存一起清；那一步要重新下载，慢一些，只有上一条没解决时才需要。

## 已知限制

- **语音音色由操作系统决定**。此模组调用的是 Minecraft 原版 TTS 引擎，该引擎只支持 `say` / `clear`，没有选择语音的接口，最终使用的是 **Windows 默认语音**。因此若系统默认语音是中文，英文播报里的数字与单位会按中文读（例如 “49 m” 读成「四十九米」）。解决办法在系统层面：**设置 → 时间和语言 → 语音 → 换一个英文默认语音**。副作用是对称的——换成英文语音后中文播报也会读得别扭。
- **ETA 未接入实际载具**。估算基于「交通方式 + 道路等级」的速度表，不读取你此刻骑的马或船的实际速度。
- **驾车只走高速与公路**。若这两个等级的片段在路网里互不连通，驾车会如实报「没有路线」。
- **离路太远会报无解**。接驳段超过上限（驾车与公共交通 64 格、步行 4096 格）时不会画直线，而是报「没有路线」。
- **MTR 只把玩家附近的线路发给客户端**。问道把每次读到的合并保留，所以走出范围不会丢，但**从没靠近过的线路**确实读不到。
- **MTR 与机械动力的线路/轨道只读**。它们的几何与站位属于那个模组，问道不会去改；想改成自己的，用线路配置界面的「复制为我的」。
- **MTR 中问道没有对应等级的类型会被忽略**（例如飞机），不会硬套成铁路。
- **小地图路标点数据源需要安装 Xaero's Minimap**；未安装时该数据源为空，其余功能正常。
- 距离单位已本地化（中文显示「米 / 千米」），但时间仍是拉丁写法（`44s`、`1h 5m`）。
- 路网规模较大时的性能尚未专门验证；当前对道路等级的查找按方块位置做了缓存。
