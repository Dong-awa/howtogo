# 在真实游戏里测这个模组（用户视角）

`tools/routing-harness/` 管的是**纯逻辑**：路网、规划、MTR 导入、线路与报站的数据模型，几秒钟出结果，
不用开游戏。它管不到的都是**玩家真正会遇到的东西**：你画的路是不是被读进来的路、你配的线路能不能
带着人横穿这个世界、报站念出来的人听不听得懂、改完以后关掉游戏再打开还在不在。这一套就是补这一半的。

## 一条命令的自检：`/howtogo selftest`

游戏里（任意存档、联机也行，客户端指令）执行：

```
/howtogo selftest
```

它会拿**当前这个世界**跑一遍：

| 检查 | 查什么 |
| --- | --- |
| 世界数据 | 路网有多少节点/路段/地点、识别到多少站点与线路、Create 轨道层与 MTR 读到了什么、当前出行方式与诊断开关 |
| 线路连通 | 每条线路相邻两站之间的判定，和线路配置界面完全同一个入口：`ok=` 连得上、`cut=` 红色（真的断开）、`unjudged=` 附近没有该类道路 |
| 线路行程 | 每条线路从首站坐到末站（最长的一趟），能不能规划出来、几段腿、几次乘车；乘车段的站序与距离必须单调递增 |
| 模拟乘车 | **把一趟真实的公交行程从 0 到终点走 48 步**，每一步问一次导航「现在会说什么」，把句子按顺序打出来——所以报告里那一串就是乘客会听到的话。缺上车、缺到站、站数不往下走都算失败 |
| 普通规划 | 取路网里相距最远的两个节点，步行与驾车各规划一次；规划不出来就连原因一起打出来 |
| 存档往返 | 把当前路网写进一个临时文件再读回来，节点/路段数必须一致（临时文件，不碰你的存档） |
| 浏览器地图 | 在一个临时端口上真的把本地网页服务开起来，取回页面、脚本、html2canvas 与 `/api/roads`，核对份数，然后关掉。回答的是回归测试答不了的两个问题：这个启动器的模块图里有没有 JDK 自带的 `com.sun.net.httpserver`，以及页面和脚本能不能透过模组自己的类加载器找到 |

它会**临时设置一个目的地再放回原来那个**（模拟乘车需要真的规划一趟），所以跑之前它会在聊天栏说一句。
完整明细同时写进日志，筛 `[HowToGo] selftest`。退出码/返回值：有失败时命令返回 0。

一次干净的世界应当全绿；出现 `FAIL` 就是模组的问题，把 `/howtogo selftest` 那段连同
`latest.log` 里筛 `[HowToGo]` 的行一起报出来即可。

## 启动 / 停止 / 重置

```powershell
.\tools\user-test\run-user-test.ps1              # 启动开发环境客户端，等模组真正加载好
.\tools\user-test\run-user-test.ps1 -Stop        # 停掉这个项目启动的客户端（不碰你自己开的）
.\tools\user-test\run-user-test.ps1 -ResetData   # 把 config/howtogo 整个备份走，从空世界重来
```

- 启动脚本只认**本项目启动的**客户端（按 `build/moddev/clientRunVmArgs.txt` 标识），不会误杀别的游戏。
- `-ResetData` 是**移动**而不是删除：备份到 `run/config/howtogo-backup-<时间戳>/`，方便对比“之前/之后”。
- 日志：`run/logs/latest.log`（模组的行都带 `[HowToGo]`）。

## 自检盖不到的部分：玩家手动清单

自检查的是数据与逻辑。下面这些只有真的点一遍才算测过（每条都写清“应该看到什么”）：

### 1. 画路与地点（世界地图 `M`，先按 `R` 进入编辑模式）

- [ ] 点几个点画一条路，再回车/右键结束 —— 路上出现一条带颜色的线，等级用 `<` `>` 切换
- [ ] 画到一半（地图上有一条跟着光标走的**紫色线**）按右键 —— 这条线结束，道路留下
- [ ] 画之前（手上没有任何线）**按住右键拖动** —— 地图跟着走；松开后没有画出任何点，也没有弹出 Xaero 的右键菜单
- [ ] 画了一条线之后、按右键结束之前，按住右键拖动 —— **不**平移地图，而是结束这条线（紫色线在的时候右键还是老功能）
- [ ] 在已有路附近落点 —— **吸附**到那条路上；按住 `Alt` 落点则自由放置
- [ ] 在路段中间落点 —— 路段被**拆开**并生成节点（后续规划能从这里拐出去）
- [ ] `-` / `+` —— 左下角读数的「道路层：」跟着变（地表 / 高架1层 / 地下1层…），接着画的路就在那一层；再按 `N` 看那条路的层，和画的时候是同一个数
- [ ] 架一条跨线桥：先画下面那条路（层 `0`），再画一条横穿它的路并选中，按 `N` 把层改成 `1` —— **桥压在下面那条路之上**；把层改成 `-1` —— **它沉到最下面**，被路面盖住
- [ ] `Shift` 点击选中一条带弯的路 —— 左下角出现「已选道路：等级 · 方向 · 道路层：… · 全长 N 格」，其中全长是**整条路**的长度（不是光标下那一段）
- [ ] `N` 命名整条路 —— 沿整条路都是同一个名字，地图上顺着路写
- [ ] `P` 放地点，再改类型为「站点」—— 地图上是站点标记
- [ ] `O` 把一条街设成单行 —— 地图上沿路出现箭头，重新规划时反向走不通
- [ ] `Ctrl+Z` / `Ctrl+Y` —— 撤销与重做各 64 步
- [ ] 关掉地图再打开 —— 画的东西还在（自动保存）

### 2. 公共交通线路（`L`）

- [ ] 「新建」建一条线路，选类型（铁路/水路/公路/冰道）
- [ ] 从右列把站点加到中列，用行尾的 `^` `v` 调序，`x` 删站
- [ ] 故意把两站放在断开的两段轨道上 —— **该站标红**，标题旁出现红字说明；把轨道接起来后红字应当**马上消失**（不用改线路）
- [ ] 站点类型与线路类型不符（比如水路线的站附近没有水路）—— 标橙提示「连通性无法判断」，**不标红**
- [ ] MTR 线路（`[MTR]` 行）—— 只读、可「复制为我的」、行尾方块可切换「标记这条线路的轨道」

### 3. 选择目的地与导航

- [ ] 打开导航终端（右键导航仪，或 `/howtogo terminal`）—— 左列地图、右列列表，搜索框可用
- [ ] 点一个目的地 —— 地图上出现**预览路线**与里程/时间
- [ ] 切「驾车 / 公共交通」与「最快 / 最短」「优先大路」「避开类型」—— 预览**当场重画**
- [ ] 「公交导航 · 只报站不报转向」**默认就是亮的**（新装 / 没有 `route_preferences.json` 时）；确认它亮着，公共交通的读数就是报站（下面第 4 条）；再点一下关掉，应当变回左转右转
- [ ] 「导航到这里」—— HUD 出现转向/报站与进度条
- [ ] 故意走偏 —— 超过容差 2.5 秒后重新规划，日志出现 `off route: ... recalculating`
- [ ] 到站 —— 出现到达横幅（「已到达」）

### 4. 公共交通的报站（默认开着「只报站不报转向」；关掉它应当变回左转右转）

依次应当听到/看到（语音开关打开时才出声）：

- [ ] 上车前：`乘坐 <线路> 往 <此方向终点站> 方向`
- [ ] 到站上车：`在 <站> 上车，乘坐 <线路> 往 <终点站> 方向`
- [ ] 每到一个站点：`现在停靠在 <当前站>，还有 n 站到达 <下车站>`
- [ ] 快到下车站：`前方到站 <站>，请准备下车`
- [ ] **到站那一刻：`到站 <站>，请下车`**
- [ ] 换乘站：快到站时`前方到站 <站>，请准备下车，换乘 <线路> 往 <终点站> 方向`，
      到站时`到站 <站>，请下车，换乘 <线路> 往 <终点站> 方向`
      （两条线**共用同一个站点**时，这一句是唯一来得及听到的换乘提示）
- [ ] 下车后：恢复成普通步行导航（有左转右转），**不再**出现「下车后步行前往目的地」

### 5. 地图显示面板与只读图层

- [ ] 面板各等级/地点类型/线路的开关能独立生效，卷起后只剩标题，位置拖动后记得住
- [ ] 缩小地图时按等级取舍：小路先消失，高速与冰道永远在，公共交通线路永不隐藏
- [ ] 装了 Create / MTR 时：铁路是只读图层，地图上有轨道与车站，但**不能编辑**

### 6. 浏览器地图（`/howtogo webmap`）

- [ ] 聊天栏里的地址是**可点击的链接**，点一下用默认浏览器打开；`/howtogo webmap status` 报的地址、世界、维度与路网规模和你看到的一致
- [ ] 地图画的是**当前维度**的路网：等级颜色、单行箭头、地点标记、路名与地点名都在；路名顺着路写、不重叠、压在路上也读得清
- [ ] **层要看得出来**：在同一个路口画一条跨线桥（选中路按 `N`，层改成 `1`），刷新页面 —— 桥压在下面的路之上，隧道（层 `-1`）在最下面
- [ ] 侧栏勾掉一个等级/一个层 —— 地图上那一批路立刻消失，统计里的数字对得上
- [ ] 拖拽平移、滚轮以光标为中心缩放、「适应窗口」回到全网；状态栏的坐标随光标变
- [ ] **「导出图片」**：下载一个 `howtogo-<维度>-<时间戳>.png`，比屏幕大（2 倍分辨率），带标题栏与图例；**遮挡与文字位置与屏幕上一致**（不是另一张图）
- [ ] 导出的那张图里，文字没有互相压住；被挤到别处的地点名仍然贴在它的标记附近
- [ ] 回到标题界面（不加载世界）刷新页面 —— 页面显示「尚未加载世界」之类的说明，而不是一张空白地图；再进世界刷新即可恢复
- [ ] `/howtogo webmap stop` 之后页面打不开；再 `start` 能起来（端口被占时会顺延，以聊天栏里的地址为准）

## 报问题
